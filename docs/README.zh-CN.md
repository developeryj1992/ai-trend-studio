# AI Trend Studio

**本地优先的 AI 热度雷达与直播内容提炼工具。**

AI Trend Studio 用于聚合公开平台热榜、提炼视频/图文内容、记录 AI 直播并生成结构化纪要。它默认在本机运行，数据保存在本地 JSON 文件中，不需要第三方账号；也可以按需接入任意 OpenAI 兼容模型，获得更高质量的摘要。

[English README](../README.md) · [架构说明](architecture.md)

## 核心能力

- 抓取抖音热榜和公开直播间、B站热门视频、微博热搜、知乎热榜。
- 用可配置关键词过滤 AI 相关内容，只保留有价值信号。
- 导入视频简介、口播稿、评论串、SRT/VTT 字幕并提炼重点。
- 按关键词搜索抖音公开直播间，一键创建直播记录会话。
- 记录单人授课或多人连线直播，支持发言人、字幕、评论、结论四类事件。
- 直播结束后生成核心结论、重点、可执行项、风险与关键词。
- 内置本地中文抽取式摘要，无 API Key 也能使用。
- 前端与图标资源本地内置，页面加载不依赖外部 CDN。
- 支持任意 OpenAI 兼容 `/chat/completions` 服务。
- 后端仅使用 Python 标准库，前端为静态页面，依赖少、易审计。

## 快速开始

```bash
python app.py
```

浏览器访问 <http://127.0.0.1:8765>。Windows 可双击 `start.bat`，macOS/Linux 可执行 `./run.sh`。

## 推荐工作流

1. 在“热榜”页刷新公开数据源。
2. 需要直播间时，在“直播间”页搜索抖音公开房间。
3. 将热门视频带入“视频提炼”，补充口播稿或字幕后生成重点。
4. 在直播前创建“直播会话”，选择单人授课或多人连线。
5. 直播中按发言人记录内容，或上传字幕/文稿。
6. 点击“完成并归纳”，生成结构化纪要。

## 平台边界

抖音热榜、公开直播间、B站热门、微博热搜、知乎热榜使用公开接口。抖音直播间搜索只在用户触发时请求公开元数据；平台要求登录时返回搜索页链接，不做绕过。小红书和受保护的抖音视频/直播间内容通常需要登录、签名或官方授权，本工具不绕过验证码、登录、风控或版权保护；这些内容可以通过用户有权使用的文字、字幕、评论或官方导出接入，再进入统一提炼流程。

## 安全与隐私

- 默认不发送内容到外部模型。
- 数据保存在 `data/db.json`。
- API Key 只写入本地数据文件。
- 页面状态和导出的 JSON 都会对 API Key 脱敏。
